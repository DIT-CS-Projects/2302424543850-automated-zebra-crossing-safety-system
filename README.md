# 2302424543850 - Automated Zebra Crossing Safety System

This project is an automated pedestrian safety system for zebra crossings. It combines a web dashboard with backend logic to monitor vehicle speed, pedestrian crossing status, distance sensing, and system health in real time.

## Features
- Real-time pedestrian crossing monitoring
- Vehicle detection and speed analysis
- Distance and safety threshold checks
- Traffic signal status display
- Dashboard for system status and events
- Web frontend + backend integration

## Tech Stack
- HTML, CSS, JavaScript
- Vite
- Python Flask
- Real-time sensor simulation logic

## Project Structure
- `src/` - frontend source code
- `public/` - static assets
- `server/` - Flask backend service
- `dist/` - production build output

## Run the project
1. Install dependencies:
   npm install
2. Start the frontend:
   npm run dev
3. Start the backend server:
   cd server
   python app.py
